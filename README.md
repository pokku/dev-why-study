# どうして勉強しないといけないの？

学校で習う内容が、将来の学問・技術・仕事・身近なものにどうつながるかを、前後へたどれる静的Webアプリです。

## 初期版の機能

- 公式・方程式、科学の図、学校、学問、興味の5方向から探す
- トップで8つの公式・方程式をMathMLで表示（E=mc²、波動、ナビエ–ストークス、マクスウェル、シュレーディンガー、運動方程式、三平方、オーム）
- 電磁波・翼のまわりの流れ・弦の振動の自作SVGから対応する式のマップへ移動
- 公式のマップに「身近な世界へ」「学校の勉強へ」の道筋、記号の意味、成立条件を表示
- 「波動方程式 → ギターの弦 → 音楽」の体験（`#lab=string`）。弦長21.7〜65cm、基本振動のスロー表示、3秒の倍音付き合成音、半分の長さとの聞き比べ、音量調整、反比例・関数・三角関数・波へのリンク
- `#labs` の体験一覧から14の体験を選択。トップと関連ノードのマップにも入口を表示
- 学校は「学校段階 → 学年・教科 → 単元」、学問と興味は「分野 → テーマ」の順に絞り込む
- 概念を選ぶと、関連知識が放射状に広がる1画面のマインドマップを表示
- PCは15ノード、スマートフォンは11ノードまでに抑え、2段先までを俯瞰
- 前提・発展・利用例と「つながる理由」は小さな補足パネルに表示
- 同じデータを使った双方向リンク
- キーワード検索
- 学習段階・科目を持つ外部JSONデータ
- PC・スマートフォン対応

## 構成

`dist/` がそのまま公開可能な静的成果物です。Cloudflare Pagesではビルドコマンドを `npm run build`、出力先を `dist` に設定します。

知識データは `dist/data/knowledge.json` にあります。ノードを追加したら、関係の理由も含むエッジを追加してください。

公式の表示と図のデータは `dist/discoveries.js`。数式は外部ライブラリを使わないネイティブMathMLです。`#explore=formula` / `#explore=science` で入口へ直接移動できます。図は概念を示す模式図で、計算結果ではありません。科学的な説明の参照元は `docs/science-sources.md` に記録しています。

```powershell
npm run validate
```

検証では、ノードIDの重複、参照切れ、孤立ノード、代表経路の断絶などを確認します。

弦の体験は `dist/string-lab.js`、理想弦の計算は `dist/string-physics.js`。張力・線密度を一定とし、波の速さ143m/s（65cmで110Hz）で `f=v/(2L)` を計算します。基本振動の図は200倍スロー、音は実周波数の倍音付き合成音です。減衰は見やすさ・聞きやすさのための演出です。音声は明示操作でのみ開始し、3秒で終了。停止・長さ変更・画面非表示・ページ離脱・別ルートへの移動で停止します。音声非対応でも図の体験は使えます。OSの動きを減らす設定では図の振動を抑制します。

`npm test` で反比例、固定端、周期性、波動方程式との数値的整合性を検証します。実機では音声開始、停止、半分の長さとの聞き比べ、スマホの戻る操作を確認してください。

## 追加した7つの体験

音の新規2体験: `#lab=harmonics`（6倍音の合成・1周期512点のフーリエ成分分析・合成音と個別成分の試聴）、`#lab=doppler`（静止した聞き手に対する音源の接近/後退・波面の広がり・音の比較・MathMLの式と数値代入）。合計14体験、102ノード・203関係。実装は `sound-catalog.js` / `sound-models.js` / `sound-labs.js`。音は明示操作で3秒、停止・設定変更・画面非表示・離脱時に終了。ドップラーの図は開始・一時停止・1コマ・初期化に対応し、自動再生せず、動きを減らす設定では1コマ送り。波面は5Hzの模式表示で、試聴は現在の速度での定常音。`npm test` はフーリエ成分の復元、位相のずれと直流成分、ドップラーの周波数と波面到着間隔の4件を加えた計22件。

電波シリーズとしてさらに4体験を追加（合計12）。`#lab=radio` はAM/FM切り替え、変調・復調波形、2種類の雑音、元の音と受信音の3秒比較。`#lab=em-wave` は電場・磁場の直交する振動、`#lab=spectrum` は周波数と波長の反比例、`#lab=polarization` はアンテナの角度と受信電力の関係を試せる。

電波シリーズは `radio-catalog.js` / `radio-models.js` / `radio-labs.js` に分離。AMは包絡線、FMは複素ベースバンドの位相差で復調。搬送波の図は8kHzの教材用で、実放送の周波数ではない。音は3秒、設定変更・停止・ページ非表示・離脱で停止し、自動再生しない。電磁波の図は規格化したスロー表示、電波スペクトルは真空中、偏波は理想的な直線偏光同士のモデル。詳細・出典・実機確認項目は `docs/science-sources.md` を参照。

知識データは100ノード・195関係。新規6ノード（AM、FM、復調、電磁波スペクトル、偏光・偏波、ラジオ）を三角関数・微積分・ベクトル・反比例や身近な音楽と接続。`npm test` は電波シリーズの6件を含む計18件。

| URLハッシュ | 操作・体験 | モデル |
|---|---|---|
| `#lab=prism` | 入射角・分散の強さを変えて色を分ける | 60°プリズムの2面でスネルの法則を計算 |
| `#lab=beats` | 周波数差を変えてうなりを聞く | 220Hzと220+Δf Hzの純音・波形・包絡線 |
| `#lab=orbit` | 初速を変えて落下・周回・脱出を比較 | GM=1の中心力、velocity Verlet法 |
| `#lab=pendulum` | 押す周期を変えて共振を比較 | 小振幅の線形振り子＋減衰＋周期外力 |
| `#lab=cancel` | 位相差を変えて強め合い・打ち消しを聞く | 同振幅の220Hzの2波を同じ出力先で合成 |
| `#lab=heat` | 板をタップして加熱し、熱を広げる | 40×24格子の陽解法、断熱境界、拡散係数≤0.24 |
| `#lab=image` | 周波数成分を減らして画像を復元 | 32×32白黒画像の正規直交DCT-IIと逆変換 |

`dist/lab-catalog.js` に題材・操作設定・説明・知識ノードを定義し、`dist/lab-models.js` に計算、`dist/science-labs.js` にUIを集約。感染の題材は含めない。

- 新規7体験は自動再生なし。動く体験には開始・一時停止・1コマ送り・初期化を用意。OSの動きを減らす設定では開始も1コマ送りにする。
- 音は明示操作で最大6秒。設定変更・停止・画面非表示・ページ離脱・ルート変更で終了。音が使えなくても図は利用可能。
- 画像はPNG/JPEG/WebP、10MiB・2000万画素以下。中央を正方形に切り出し、端末内で32×32白黒に縮小。サーバー送信・永続保存なし。画像の差分は128を差0として表示し、表示範囲を超える値はクリップする。
- `npm test` は既存の弦4件と、屈折・軌道・共振・干渉・熱保存・DCT復元などの8件を検査する。`npm run build` は体験のノード参照・ID重複・操作範囲も確認する。
